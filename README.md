# Lalit Khode - Developer Portfolio

A responsive dark-themed personal portfolio built with HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in your browser, or use the VS Code Live Server extension.

## Deploy on Render
1. Push these files to a GitHub repository.
2. In Render, choose **New + → Static Site**.
3. Connect your GitHub repository.
4. Set the build command to blank (no build step is needed).
5. Set the publish directory to `.`.
6. Deploy.

## Customize
Update your details, education, skills, links, and project information in `index.html`.
